# tests

| Path | What it holds |
|---|---|
| [`programs/`](programs/) | Runner lab programs: one C file per capability or known gap |
| `lab.js` | The programs with gcc's results, generated by `tools/build-tests.js` |
| `check.js` | Compares one runner result with gcc's (known gaps are reported, not failed) |
| `run-node.js` | Runs the whole lab in Node |
| `search.test.js` | Queries a reader would type, in every language, against the real course data |

```sh
node tests/run-node.js
node tests/search.test.js
```
